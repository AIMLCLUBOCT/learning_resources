# Contributing to Learning Resources

We welcome educational contributions from students, faculty mentors, and community members!

---

## What Can You Contribute?
- **Concept Explanations:** Clear, intuitive markdown guides for complex AI/ML topics.
- **Hands-on Exercises:** Practice problems, code notebooks, and solution explanations.
- **Resource Additions:** Verified links to official documentation, academic papers, and interactive tutorials in [`resources.md`](./resources.md).
- **Roadmap Improvements:** Suggestions to make learning paths more approachable or up-to-date with current industry standards.

---

## Guidelines for Submissions

1. **Official Documentation First:** When linking references, always prioritize official documentation (e.g., Python docs, scikit-learn, PyTorch, TensorFlow) over personal blogs or unauthorized reposts.
2. **Pedagogical Structure:** Every module guide should follow the standard structure:
   - Prerequisites
   - Core Concepts
   - Recommended Learning Sequence
   - Practical Hands-on Exercises
   - Project Ideas
   - Official References
3. **No Plagiarism:** Explain concepts in your own words. Attribute external diagrams, quotes, or code snippets clearly.
4. **Formatting:** Use standard GitHub markdown, descriptive headings, and proper code blocks with syntax highlighting.
5. **PR Flow:** Create a branch (`feat/add-topic-notes`), make your edits, verify formatting locally, and open a Pull Request against `main`.
